`Z-Image 终极工坊 Pro (人像专区)` 是一款专为 AI 绘图（Midjourney / Stable Diffusion 等）创作者设计的**单文件、免安装、可本地运行**的提示词管理与灵感激发工具。

本版本为纯净精炼版，彻底剥离冗余模块，仅保留核心的**“人像专区（灵感画廊）”**，提供极致流畅的提示词浏览、实时编辑与快速复制体验。

---

## ✨ 核心特性

- **🚀 零部署，双击即用**：纯单页 HTML 文件，无任何后台服务，下载后双击即可在本地浏览器中完美运行。
- **🎨 瀑布流灵感卡片**：采用精美的响应式瀑布流布局，自适应 PC、平板和手机端。
- **📝 实时在线编辑**：支持直接在卡片上点击修改文本（`contenteditable` 属性），边看边改，无需跳出。
- **📋 智能高效复制**：
  - **单卡复制**：一键复制单张卡片内容（包含您在线修改后的最新文本）。
  - **一键打包**：一键复制当前页面展示的所有灵感提示词。
- **🔄 随机换一批**：点击“换一批”按钮，系统将从您的本地数据库中随机抽取 10 条灵感重新排版呈现。
- **💾 零门槛数据录入**：底部自带文本存储区，直接粘贴原始文本（用空行分隔）即可完成数据库更新，无需任何代码基础。

---

## 🚀 快速上手

### 1. 运行项目
1. 下载仓库中的 `Z-Image-终极工坊Pro.html` 文件。
2. 双击该文件，直接在任意现代浏览器（Chrome, Edge, Safari 等）中打开即可。

### 2. 提示词的编辑与复制
* **编辑**：直接用鼠标点击卡片内的文字，即可直接输入或删减内容。
* **复制单条**：点击卡片右上角的 **“复制”** 按钮，复制当前修改后的内容。
* **复制全部**：点击顶部导航栏的 **“复制本页全部”**，一键打包整页提示词。
* **切换灵感**：点击顶部的 **“换一批”**，随机加载其他缓存的人像提示词。

## ⚙️ 如何自定义您的专属提示词库（极简录入）

无需修改繁琐的 JavaScript 数组，只需用文本编辑器（如记事本、VS Code、Sublime Text）打开 `Z-Image-终极工坊Pro.html` 文件，滚动到最底部，找到如下标签：

```html
<!-- 定位到文件底部这一行 -->
<script id="raw-prompts" type="text/plain">

在这里直接粘贴您的提示词，
每段提示词之间只需保留一个【空行】即可。

这是第二段提示词，
系统会自动将其识别并切分为独立的卡片。

这是第三段提示词...
</script>
